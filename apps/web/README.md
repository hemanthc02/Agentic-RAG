# apps/web — Next.js 15 frontend

Premium SaaS UI per `documentcreation/ui-ux-specification.md`. Stack: Next.js 15
(App Router), React 19, TypeScript, Tailwind, shadcn/ui, Framer Motion, TanStack
Query, Zustand, React Hook Form + Zod. Dark-mode-native, WCAG 2.1 AA.

Planned routes: `/onboarding`, `/dashboard`, `/corpora`, `/ask` (the hero:
streamed answer + per-claim verification panel), `/history`, `/evaluations`,
`/settings`, `/admin`. Consumes types generated from `packages/shared-types`.
Built in step 13.
